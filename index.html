Open Architecture

Built for Resilience & Privacy

🧠

Google Gemma Open Weights

Runs locally via Ollama with Gemma 2B. Sub-4GB memory budget makes it ideal for laptops and edge devices like Raspberry Pi 5.

🌲

100% Offline Edge Vision

Analyzes RGB chlorophyll saturation, chlorosis, and necrotic pixel ratios locally using Pillow when deep in the backcountry.

🔒

Zero Telemetry Privacy

Your garden layout, harvest data, and GPS soil coordinates never leave your machine. Absolute local sovereignty.

🤝

Companion Planting Synergy

Built-in permaculture companion matrices highlighting beneficial pairs (Tomatoes + Basil) and antagonistic pairings to avoid.

📋

Downloadable Field Cards

Generates ready-to-print Markdown field cards with triage steps and organic spray recipes for your potting shed.

🐝

Bee-Safe Organic Remedies

Developer Quickstart

Run Locally in 60 Seconds

bash • florasprout-setup
# 1. Clone the repository
git clone https://github.com/LakshChinchmalatpure/HacktoberFest_Weekday01_PlantCare_AI.git
cd HacktoberFest_Weekday01_PlantCare_AI

# 2. Install lightweight dependencies
pip install -r requirements.txt

# 3. (Optional) Run Gemma with Ollama
ollama run gemma:2b

# 4. Launch the Streamlit application
streamlit run app.py
